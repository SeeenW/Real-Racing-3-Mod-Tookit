# Part names the game recognises

Read from `liveryStringTable.bin.nct` (the table the engine itself consults).
A mesh name that is not in this list has **no livery slot**, so the engine
falls back to the material the m3g already carries.

- 1869 full names
- 948 base names
- 30 material tags
- LOD letters: (no LOD)=2, `A`=695, `B`=364, `C`=251, `D`=223, `E`=202, `F`=127, `G`=4, `H`=1

## How a name is built

```
LOD_<letter>_<BASE>_mm_<tag>
```

- `<letter>` is one of `A B C D E F G H`.  Body LODs are `A`..`H`; the
  shared wheel file is not a LOD and its meshes carry no livery slot.
- `<BASE>` is one of the base names in the second list below.
- `<tag>` is one of the material tags.  It decides *which* material slot the
  mesh asks for, so the same base with a different tag is a different part.

Example: `LOD_A_WING_REAR_LEFT_mm_misc` = LOD A, base `LOD_A_WING_REAR_LEFT`,
tag `misc`.

## Material tags

| tag | what it is |
|---|---|
| `badges` | badges and decals |
| `banner` | windscreen banner |
| `cab` | cockpit / cabin |
| `chassis` | chassis and suspension |
| `cloak` | car cover |
| `ext` | outer body paint |
| `headlight_glow` | headlight glow card |
| `int` | interior trim |
| `lights` | lamp glass |
| `mat00` | generic material 00 |
| `mat01` | generic material 01 |
| `mat02` | generic material 02 |
| `mat03` | generic material 03 |
| `mat04` | generic material 04 |
| `mat05` | generic material 05 |
| `mat06` | generic material 06 |
| `mat07` | generic material 07 |
| `misc` | miscellaneous body parts (grilles, vents, plastic) |
| `rotor` | brake disc |
| `scratches` | damage overlay |
| `sidelight_glow` | sidelight glow card |
| `sw` | steering wheel |
| `taillight_glow` | taillight glow card |
| `tyre` | tyre |
| `wheel` | rim |
| `wheel_blur` | rim, motion blurred |
| `windows` | glass |
| `windows001` | glass, variant |
| `windows_cracked` | damaged glass |
| `windows_shattered` | broken glass |

## The ones a new car actually needs

A car does not have to use all 948 bases.  The shipped minimum is roughly:

| purpose | name |
|---|---|
| body | `LOD_A_BODY` + tag: `badges`, `cab`, `chassis`, `ext`, `lights`, `misc`, `windows` |
| chassis | `LOD_A_CHASSIS` + tag: `badges`, `cab`, `chassis`, `ext`, `lights`, `misc` |
| glass front | `LOD_A_GLASS_FRONT` + tag: `ext`, `misc`, `windows` |
| glass rear | `LOD_A_GLASS_REAR` + tag: `misc`, `windows` |
| glass left | `LOD_A_GLASS_LEFT` + tag: `badges`, `ext`, `misc`, `windows` |
| glass right | `LOD_A_GLASS_RIGHT` + tag: `badges`, `ext`, `misc`, `windows`, `windows_cracked` |
| door left | `LOD_A_DOOR_LEFT` + tag: `badges`, `cab`, `chassis`, `ext`, `lights`, `misc`, `windows` |
| door right | `LOD_A_DOOR_RIGHT` + tag: `badges`, `cab`, `chassis`, `ext`, `lights`, `misc`, `windows` |
| frontbumper | `LOD_A_FRONTBUMPER` + tag: `badges`, `cab`, `chassis`, `ext`, `lights`, `misc`, `windows` |
| rearbumper | `LOD_A_REARBUMPER` + tag: `badges`, `cab`, `chassis`, `ext`, `lights`, `misc`, `windows` |
| hood | `LOD_A_HOOD` + tag: `badges`, `cab`, `chassis`, `ext`, `lights`, `misc`, `windows` |
| boot | `LOD_A_BOOT` + tag: `badges`, `cab`, `chassis`, `ext`, `lights`, `misc`, `windows` |
| mirror left | `LOD_A_MIRROR_LEFT` + tag: `badges`, `cab`, `chassis`, `ext`, `lights`, `misc` |
| mirror right | `LOD_A_MIRROR_RIGHT` + tag: `badges`, `cab`, `chassis`, `ext`, `lights`, `misc` |
| steering wheel | `LOD_A_STEERING_WHEEL` + tag: `cab`, `ext` |
| interior | `LOD_A_INTERIOR` + tag: `badges`, `cab`, `ext`, `lights`, `misc` |
| exhaust | `LOD_A_EXHAUST` + tag: `chassis`, `ext`, `lights`, `misc`, `wheel` |
| wheelguard front left | `LOD_A_WHEELGUARD_FRONT_LEFT` + tag: `chassis`, `ext`, `lights`, `misc` |
| wheelguard front right | `LOD_A_WHEELGUARD_FRONT_RIGHT` + tag: `chassis`, `ext`, `lights`, `misc` |
| wheelguard rear left | `LOD_A_WHEELGUARD_REAR_LEFT` + tag: `chassis`, `ext`, `misc` |
| wheelguard rear right | `LOD_A_WHEELGUARD_REAR_RIGHT` + tag: `chassis`, `ext`, `misc` |

The **wheels are not in the body file**.  They live in
`<car>_shared.m3g` and are named `LOD_A_WHEEL_mm_wheel`,
`LOD_A_TYRE_mm_tyre`, `LOD_A_ROTOR_mm_rotor` and so on - same shape, but
the letter is always `A` there because the shared file has one LOD.

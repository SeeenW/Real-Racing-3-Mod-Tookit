### 2.1 flags 含义

| flag | 含义 |
|---|---|
| `FOG` | 参与雾计算 |
| `SPEC_TEXTURE` | 用镜面贴图（车漆的高光形状就靠它） |
| `SPEC_MASK_TEXTURE` | 镜面遮罩，按 UV 决定哪里亮 |
| `REF_TEXTURE_MASK` | 用反射贴图的 alpha 当遮罩 |
| `COLOURED_FRESNEL` | 菲涅尔带色（糖果漆 / 珍珠漆的边缘色） |
| `SPEC_FLAKES` | 金属闪片（`metallic_spec_*`） |
| `ROTOR_GLOW` | 刹车盘余热发光 |
| `ALPHA_MODULATE` | 半透明 |

## 4. 部件名（1869 个）

### 4.1 命名规则

```
LOD_A_WING_REAR_LEFT_mm_ext
^^^^^ ^^^^^^^^^^^^^^^ ^^ ^^^
LOD  基名             _mm_ 标签
```

- `LOD_A` .. `LOD_H`：细节级别，A 最精细。老车常常只有 A–D。
- 基名：引擎按它查 liveries 槽位，**所以同名不同 LOD 是不同槽位**。

## 6. 动画片段名（12 个）

`<car>_animations.xml` 里只有这些 `<anim name=...>` 会被引擎查询。
**1 帧 = 33.0 ms（30.303 fps）**，`end < start` 表示倒放。

| 片段名 | 含义 |
|---|---|
| `wing_initial` | rest pose (folded / retracted) |
| `wing_race_initial` | rest pose used during a race |
| `wing_up` | extend the aero (brake flap up) |
| `wing_down` | retract the aero |
| `pivot_up` | raise the moving pivot |
| `pivot_down` | lower the moving pivot |
| `neutral_to_speed` | spoiler neutral -> high-speed position |
| `speed_to_neutral` | high-speed -> neutral |
| `speed_to_brake` | high-speed -> air-brake position |
| `brake_to_speed` | air-brake -> high-speed |
| `neutral_to_brake` | neutral -> air-brake |
| `brake_to_neutral` | air-brake -> neutral |

行为设置（`DeployWhenBraking` 等）写在车的 spec 里，不在 XML 里，见
`docs/插件使用手册.md` §7。

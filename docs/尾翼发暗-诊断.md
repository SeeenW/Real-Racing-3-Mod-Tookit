## 0. 一句话结论

**不是材质丢了，也不是 81B/byte17/byte26/尾块的锅。** 我们的尾翼节点 `LOD_A_WING_REAR` 里被塞进了
**两个材质组**：`_mm_ext`（车漆，598 三角 / 0.715 m²）和 **`_mm_misc`（黑色塑料，808 三角 / 0.623 m²）**。
后者用的是 `Vehicle Exterior_mm_misc` → 图集 `2012_lexus_lfa_misc.dxt.dds.z`（发动机舱 / 黑塑料图集），
而且这 808 个三角的 UV 在原厂就是一条 **33×1 像素的塌陷条带，落点纯 (0,0,0)**。
所以尾翼表面 **47% 的面怎么画都是黑的**（朝上那面 47%、朝下那面 46%），光一打整体就显得"发暗、几乎全黑"。

一句话修法：**别把这 808 个 `_mm_misc` 三角切进尾翼节点**（留在车体里），或者把它们改成车漆材质 + 指向漆面纹素。

### 这两个材质组在原厂车身上是什么

用刚体不变量把尾翼三角反查回原厂车身（旋转/平移不变）：

| 组 | 命中 | 面积 | 原厂空间 bbox（质心） | 朝上 / 朝下 |
|---|---|---|---|---|
| `_mm_ext`（车漆） | 588 / 598 | 0.715 m² | y 0.829..0.960, z 1.715..2.076 | 24% / 27% |
| `_mm_misc`（黑塑料） | 802 / 808 | 0.623 m² | y 0.703..0.932, z 1.626..1.993 | 44% / 18% |

- 位置：后风挡（`LOD_A_GLASS_REAR_mm_windows` y 0.957..1.173, z 0.899..1.841）之后、后保险杠
  （`LOD_A_REARBUMPER` y 0.119..0.612, z 1.605..2.248）之上的**后甲板**。
- `_mm_misc` 组整体比 `_mm_ext` 组低约 **10 cm**（在漆面下面/里面）⇒ 原厂里它是**藏在漆面下方/内部的那一层**。
- 面积占比：**`_mm_misc` 占尾翼总表面积 47%**（上表面 47%、下表面 46%）——不是边角料，是半只尾翼。

## 3. 为什么它会被切进尾翼

切分判据（`analysis/split_wing_components.py:30,104-111`、`analysis/split_wing_from_body.py:53,97-103`、
`inplace_wing.py:29`、`inplace_wing2.py:40`、`split_wing_factory.py:20` 全是同一组常数）：

```
Z_MIN, Y_MIN = 1.55, 0.60
...
is_wing = cz > Z_MIN and cy > Y_MIN     # cz/cy = 连通分量（或三角）质心
PAIRS = [("LOD_A_BODY_mm_ext",  "LOD_A_WING_REAR_mm_ext"),
         ("LOD_A_BODY_mm_misc", "LOD_A_WING_REAR_mm_misc")]
```

- 判据只看**位置**，**没有"只切 `_mm_ext`"这一条**；`PAIRS` 明确把 `_mm_misc` 也一起切了。
- 框的范围（复算）：原厂 `LOD_A_BODY_mm_ext` 落在框内 1994 三角 / 1.809 m²、
  `LOD_A_BODY_mm_misc` 落在框内 1072 三角 / 0.642 m² —— 我们的 598/808 是框内再按连通分量筛出来的。
- `split_wing_components.py` 的文件头自己也写了这个坑：*"v47 split by a bounding box (z>1.55, y>0.60)
  and dragged a chunk of bodywork along with the wing"*；同一段注释还写明 `_mm_misc` 里"空力分量 =
  408 三角的**叶片下表面** + 侧板 + 撑杆"。
- 尾翼一旦被 `.banim` 整体抬起/翻转，这层原本藏在漆面下面的黑塑料就**整片露出来**（悬在车尾上方），
  从追车视角看就是"尾翼几乎全黑"。这也解释了为什么 MonkeyTool 导出的同类文件同样发暗——
  只要用了同一个框/同一套"ext+misc 一起切"的逻辑，就一定带上它。

## 4. 修复方案

### 方案 A（推荐，最小改动，原地改现有 v37，不用重导）

把这 808 个 `_mm_misc` 三角从尾翼节点里摘掉，尾翼只剩 598 个漆面三角。
**改动只有一处字节**：把 `LOD_A_WING_REAR_mm_misc` 那个 IndexBuffer 清空（索引数 2424 → 0）。
不增删对象、不改任何引用、不动材质表 ⇒ 不存在"引用对不上"的风险。

```
python analysis/fix_wing_dark.py re\lfa\2012_lexus_lfa_a_v37.m3g re\lfa\diag\v37_wing_drop.m3g --mode drop
# 产出：re\lfa\diag\v37_wing_drop.m3g（2,102,866 B，492 对象，0 warning）
#   LOD_A_WING_REAR_mm_ext  mat=0 v=1794 t=598
#   LOD_A_WING_REAR_mm_misc mat=6 v=2424 t=0     <- 不画了
```

依据：那 808 三角在原厂里就是低 10 cm 的内层、UV 塌陷成单色黑，本质是"看不见的内表面"；
不画它们在车体视角与原厂等价。**代价**：尾翼变成一个"薄壳"（漆面单面），从正下方看会透视过去。

### 方案 B（想要"整只尾翼都是车漆色"就用这个）

把这 808 三角改成车漆：`materialId 6 → 0`，并把它们的 UV 全部重指向叶片漆面用的那个涂装纹素
（涂装是 mask，单个纹素 = 单一车身色）。两处都是等长字节替换，文件大小不变。

```
python analysis/fix_wing_dark.py re\lfa\2012_lexus_lfa_a_v37.m3g re\lfa\diag\v37_wing_repaint.m3g --mode repaint
# 产出：re\lfa\diag\v37_wing_repaint.m3g（2,107,714 B，原样大小）
#   materialId 6 -> 0；VERTEX_ARRAY#280 全部 2424 顶点的 UV -> raw(1281,-80) = uv(2.5020, 0.8438)
#   （该纹素取自 ext 叶片 UV 的中位数，保证落在漆面内部）
#   LOD_A_WING_REAR_mm_ext  mat=0 t=598 / LOD_A_WING_REAR_mm_misc mat=0 t=808
```

依据：材质 id 0 = `Vehicle Exterior_mm_ext`，与车身漆面同一路；UV 指向叶片漆面纹素 ⇒ 得到纯车身色
（不会出现条纹/贴错图）。风险：`_mm_ext` 是带 fresnel/清漆的漆材质，下表面也会被当成车漆算高光，
观感偏"塑料"但至少不再是黑的。

### 方案 C（重导：把判据修对）

要根治，改导出逻辑，**两处**：

1. `analysis/split_wing_components.py`
   - 第 31–32 行 `PAIRS`：删掉 `("LOD_A_BODY_mm_misc", "LOD_A_WING_REAR_mm_misc")` 这一项
     （即**尾翼只从 `_mm_ext` 切**）；
   - 或保守一点：保留 misc 组但把 `Y_MIN` 从 `0.60` 提到 **`0.83`**（`_mm_misc` 组的质心最高只到 0.932，
     而漆面叶片从 0.829 起；提高到 0.83 会把这层内衬留在车体），并在第 110 行加一条
     `and mat_id == 0`。
2. `analysis/split_wing_from_body.py:54-55`、`inplace_wing.py` / `inplace_wing2.py` / `split_wing_factory.py`
   的 `PAIRS` / `Z_MIN,Y_MIN` 同步改，否则下次重导又带回来。

如果导出器（Blender 侧）自己也按部件名分组，则对应逻辑是"部件 `LOD_A_WING_REAR` 只接受
`Vehicle Exterior_mm_ext` 材质组"——把 misc 组留在 `LOD_A_BODY`。

## 9. 【2026-10-27 结案】真正的修法不在 m3g 侧

本文第 0~8 节的**取证全部有效**（同一像素着色器、不同 LUT、`_mm_misc` 图集纯黑、
索引数量被引擎硬性假设），但"修法"部分已被推翻。

真正的机制：`liveries/<车>.liveries.bin.nct` 里有 **4 张表**，之前所有工具都只解了第 1 张
「贴图表」。**第 2 张「网格 → 材质」表和每个涂装里的「材质覆盖」表就是官方的
「零件 → 材质」映射**，它决定 part 的材质集，材质集决定引擎绑哪张 LUT
（`binding=2` 车身漆 vs `binding=4` 的 `car_flat`）。

我们的 611 的 liveries 是从 LFA 克隆的，LFA 原厂没有 WING 网格 ⇒ 表里没有
`745 LOD_A_WING_REAR_mm_ext` 条目 ⇒ 引擎退回默认 `car_flat`。

修法：给每个涂装的材质覆盖表补一条 `745 -> 与该涂装 30 (LOD_A_BODY_mm_ext) 相同的材质`。
已落地并实机验证：**尾翼和车身同色同光泽，跟随车漆类型变化**。

详见 `docs/livery槽位表与材质名.md` §2 与 `docs/HANDOFF-20261027.md`。

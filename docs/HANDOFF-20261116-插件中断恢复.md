## 5. 踩过的坑（写进会话记忆，避免重复踩）

1. **不要把 `from rrmod import publish as publishlib` 写进 `main()`** —— 会让整个函数里
   `publishlib` 变局部变量，抛 `UnboundLocalError`。模块顶层已有该 import。同理 `texpages`、`depslib`、`modlib`。
2. 测试用 PNG 必须和原页**同尺寸**（`car_windows_04` 是 512×512）；64×64 会报
   `TextureError ... this does not rescale`。
3. 写出来的页是 zlib 压缩的（`.dds.z`），断言前要 `pvrlib.inflate_z(...)`。
4. `ddsdecode.decode(data)` 返回**元组** `(w, h, channels, pixels)`，不是 dict。
5. ETC 像素序 `x = i >> 2, y = i & 3`；ATC 是 `x = i & 3, y = i >> 2` —— 写反了照样能解出图，
   只能逐像素比对抓。
6. `ensure_data` 只镜像 `vehicles/data`，`gametext.txt` 在 `.depot` 根 —— 工作副本里没有，
   读不到文本表要回落到 `Glyph U+2605` / 图片文件名。
7. Windows 上不要把 `newline=` 从 here-string 传给写入函数 —— 旧会话曾两次把
   `rrmod/deps.py` 截成 0 字节。

# 锚点名清单（.points）

从全部 960 个 `.points` 文件里统计出来的**全部 176 个锚点名**：`<car>.points` 里 142 个，
`<car>_int.points` 里 40 个，其中 34 个只在 `_int` 里出现（仪表针、挡杆、后视镜内框这些内饰专用锚点）。
游戏按名字找挂载点：名字打错，部件就找不到位置。

数据来源：`<depot>/vehicles/<car>/<car>.points`（另有 `<car>_int.points` 是内饰用的）。
解析入口：`rr3lib/points.py` 的 `load(path)`，记录字段 `name / type / position / matrix`。
校验入口：`rr3lib/points_write.py` 的 `engine_name()` / `validate()`，Blender 导出时会逐条报出"游戏会忽略"的名字。

## 四种类型

| `type` | 含义 | 全库条数 |
|---|---|---|
| `point` | 一个位置（灯、排气、驾驶员、轮心…） | 6543 |
| `hinge` | 一个铰链（门、盖、镜、悬挂摆臂…） | 3486 |
| `spline` | 一条样条（高光条、倒车灯带） | 328 |
| `transform` | 一个变换（排气方向、拉力赛视角） | 16 |

**新车最少需要 4 个**：`POINT_WHEEL_FL` / `FR` / `BL` / `BR`，否则轮子没地方装（463/463 台都有）。

## 引擎到底认哪些名字：79 个基名 + 后缀规则

引擎里有一张 **79 个基名**的表（`.so` 里 `0x01EEB458`）。查找时**先剥掉名字末尾的一串数字**，
再查表，所以 `POINT_HEADLIGHT_LEFT_01` / `_09` / `_003` / `1` 都落到基名
`POINT_HEADLIGHT_LEFT` 上，一台车可以有任意多组大灯。这就是"表里只有 79 个名字，
实车却用出 176 个"的原因。

**后缀规则**（`points_write.engine_name()`）：

```
POINT_HEADLIGHT_LEFT_01  ->  POINT_HEADLIGHT_LEFT   ✓ 认
POINT_HEADLIGHT_LEFT_2   ->  POINT_HEADLIGHT_LEFT   ✓ 认（前导零可有可无）
POINT_WHEEL_FL001        ->  POINT_WHEEL_FL         ✓ 认（数字直接粘着也行）
POINT_BRAKELIGHT_BOOT_01 ->  POINT_BRAKELIGHT_BOOT  ✗ 基名本身就不在表里
```

## 表里有、但实车从不单用的 16 个基名

`POINT_LIGHTBAR_*`（5 个）、`POINT_NEEDLE_LINEAR_RPM` / `_LINEAR_SPEED`、
`POINT_STEERING_WHEEL_NEEDLE_*`（4 个）、`HINGE_STEERING_WHEEL_NEEDLE_SPEED`、
`HINGE_WING_REAR`、`POINT_INTERIOR_HUD`、`POINT_UNDERBODY_SPARKS`——
原厂一律带 `_01` 之类后缀使用。你自己写的时候两种都行。

## 原厂自己写错的（**别学**）

| 写法 | 应该是 | 出现在 |
|---|---|---|
| `HINGE_BOOD_LEFT` / `HINGE_BOOD_RIGHT` | `HINGE_HOOD_*` | 各 1 台 |
| `POINT_BRAKELIGHT`（光秃秃） | `POINT_BRAKELIGHT_LEFT` / `_RIGHT` | 28 台 |
| `POINT_BRAKELIGHT_BOOT` `_01` `_02` | 表里没有，引擎忽略 | 11 台 |
| `POINT_NEEDLE_RPM_MIN` / `_MAX` | 表里没有（`MIN`/`MAX` 不是数字，剥不掉） | 各 1 台 |
| `POINT_EXHAUST_S04` | `POINT_EXHAUST_04` | 1 台 |
| `HINGE_NEEDLE_SPEED_03` | `HINGE_NEEDLE_SPEED_3` | 1 台 |

这些是资产本身的笔误，游戏不校验、也不报错，只是那个锚点永远没人用。

| 1 | `HINGE_NEEDLE_SPEED_03` | 时速针铰链（引擎不认，见上） |
| 1 | `HINGE_STEERING_WHEEL_NEEDLE_RPM_1`… | 方向盘小表针铰链（带编号写法） |

指针类锚点的约定：`POINT_NEEDLE_*` 是**轴心位置**，`HINGE_NEEDLE_*` 是**同一位置的铰链**，
两者的位置应该重合；指针的零位朝向由铰链的 3×3 决定（见 `points-格式.md`）。



## 建新车时该用哪些

| 用途 | 名字 | 必需 |
|---|---|---|
| 四个轮心 | `POINT_WHEEL_FL` / `FR` / `BL` / `BR` | **必需** |
| 驾驶员与方向盘 | `POINT_DRIVER` | 强烈建议 |
| 大灯 | `POINT_HEADLIGHT_LEFT` / `RIGHT`（多灯组用 `_01` `_02` …） | 建议 |
| 尾灯 | `POINT_BRAKELIGHT_LEFT` / `RIGHT` | 建议 |
| 排气 | `POINT_EXHAUST_01` … `_04` | 可选 |
| 后视镜 | `HINGE_MIRROR_LEFT` / `RIGHT` | 可选 |
| 门 | `HINGE_DOOR_LEFT` / `RIGHT` | 可选 |
| 引擎盖 / 后备箱 | `HINGE_HOOD_LEFT`/`RIGHT`、`HINGE_BOOT_LEFT`/`RIGHT` | 可选 |
| 前后保险杠 | `HINGE_FRONTBUMPER_*`、`HINGE_REARBUMPER_*` | 可选 |
| 悬挂摆臂 | `HINGE_STRUT_{UPPER,LOWER}_{FRONT,REAR}_{LEFT,RIGHT}` | 可选（有轮子才渲染） |
| 转向 | `HINGE_STEERING_ARM_*`、`POINT_STEERING_ARM_ANCHOR_PIVOT_*`、`POINT_STEERING_STRUT_*_END` | 可选 |
| 高光条 | `SPLINE_SPECULAR` / `SPLINE_SPECULAR_REVERSE` | 可选（车身流线用） |

## 坐标与单位

- **单位**：`.points` 里的原始值是 1/32 米（`rr3lib/parts.py:POINT_SCALE = 1.0 / 32.0`）。
- **轴**：引擎空间 `x` 向右、`y` 向前、`z` 向上；写进 Blender 要过 `parts.anim_to_model()`。
- **轮心高**：等于一个轮胎半径（模型原点在地面），**不需要任何 height offset**。

## 名字格式的坑

游戏**不校验**名字，拼错了不报错，只是部件永远找不到挂载点。上面那些"变体写法"
（`POINT_WHEEL_BL001`、`POINT_EXHAUST_032`、`HINGE_BOOD_LEFT`、`POINT_HEADLIGHT_LEFT_1`）
是原厂资产自己的笔误，**不要模仿**，用规范写法。

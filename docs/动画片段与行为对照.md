## 3. 行为串分布（全部 540 台车）

行为串是 spec 里 `generic_race` 字符串**前一个** token，格式是**自由文本 + 逗号参数**，引擎按前缀认：`<行为名>[, <参数1>, <参数2>]`。

| 行为串 | 含义 | 台数 |
| --- | --- | --- |
| （空 token / 无 `generic_race`） | 空 token —— 没有行为 | 476 |
| `NascarAirBrake` | NASCAR 专用空气刹车 | 40 |
| `DeployWhenBraking` | 刹车时展开 | 13 |
| `PaganiHuarya` | Huayra 的活动襟翼（官方拼写就是 Huarya） | 2 |
| `DeployAtSpeed, 120, 60` | 到达某个速度时展开/收回，两个参数是速度阈值 | 2 |
| `EngineFan` | 引擎风扇（Porsche 917K / 909 Bergspyder） | 2 |
| `BrakeAndSpeedCombo, 180, 170` | 刹车 + 速度组合触发，两个参数是速度阈值 | 2 |
| `BrakeAndSpeedCombo, 120, 80` | 刹车 + 速度组合触发，两个参数是速度阈值 | 1 |
| `DeployAtSpeed, 275, 220` | 到达某个速度时展开/收回，两个参数是速度阈值 | 1 |
| `None, 180, 170` | 行为名是 None，但参数在 | 1 |

| `BrakeAndSpeedCombo, 180, 170` | 2 | 2 | 0 |
| `PaganiHuarya` | 0 | 0 | 2 |
| `EngineFan` | 0 | 0 | 2 |
| `BrakeAndSpeedCombo, 120, 80` | 1 | 1 | 0 |
| `DeployAtSpeed, 275, 220` | 1 | 1 | 0 |

**注意：34 台车完全没有行为串（空 token）却照样有完整动画。**
所以 `DeployWhenBraking` 不是「有尾翼动画」的必要条件 ——
`.banim` + `.xml` 决定**能不能动**，行为串只决定**什么时候动**。

## 2. 贴图垂直翻转

### 2.1 权威依据

MonkeyTool 是**翻图片、不翻 UV**：

```cpp
// re/mt/Monkey-Tool-main/src/nfsnl_image.cpp:1100  decodeImageAuto()
flipImageVertically(out);     // 无条件
// 注释："Real Racing 3's DDS files are bottom-up too - 0.7 assumed the format's
//        own top-down convention and showed the Koenigsegg badge sheet upside
//        down - so everything is turned over here."

// re/mt/Monkey-Tool-main/src/nfsnl.h:530
Model loadM3g(const uint8_t* data, size_t len, bool flipV = false);   // 默认不翻
```

`nfsnl_rr3.cpp:1765-1789` 的 UV 导出注释也印证这对搭配：

> "V runs from 0 down to -1 in the file, and the textures are stored bottom-up,
> so the export value is 1 + v: that puts the map the right way up against the
> flipped texture."

我们的 UV 变换（`v' = (1-v)/4`）本来就等价于它的 `1+v`，缺的只是**翻图片**。

### 2.2 实现

`rr3lib/texport.py`：

```python
FLIP_V = True                      # 游戏贴图是 bottom-up

def flip_rows(width, height, channels, pixels) -> bytes:
    stride = width * channels
    out = bytearray(len(pixels))
    for y in range(height):
        src = (height - 1 - y) * stride
        out[y * stride:(y + 1) * stride] = pixels[src:src + stride]
    return bytes(out)

def export_png(path, out_path, frame=0, flip_v=None):
    width, height, channels, pixels = decode_frame(path, frame)
    if FLIP_V if flip_v is None else flip_v:
        pixels = flip_rows(width, height, channels, pixels)
    ...
```

`rr3_blender_addon/__init__.py` `_image_for_path()` **所有容器统一走 `texport.export` 出 PNG**
（包括普通的 `.dds.z`，以前直接交给 Blender 的 DDS 解码器，会绕过翻转）：

```python
png = texportlib.export(path, _image_cache_dir(), "png")
img = bpy.data.images.load(png, check_existing=True)
```

> 试过但**不能**当判据的（记录下来省得重走）：UV 包围盒不透明率（A 68.9% / D 59.6%）、

## 3. 着色参数：`Specular Tint` 必须除以 255

### 3.1 根因

`gamematerial.Library.spec_colour()` 返回的是 `mu_MaterialSpecularColour_Base` 的**原样字节**
（`255,255,255`、`512,512,512`、`90,160,209`…），而 Blender 的 `Specular Tint` 是 0..1 的颜色。
旧代码直接 `_set_input(bsdf, "Specular Tint", (*rm.spec_colour, 1.0))`，等于把高光放大 255 倍。

导入后实测（修前）：

```
car_paint_gloss_paint    base=(0.91,0.722,0.031) specTint=(255,255,255) rough=0.045
car_glass_paint          base=(0.8,0.8,0.8)      specTint=(512,512,512) rough=0.063
car_wheels_chrome_paint  base=(0.8,0.8,0.8)      specTint=(255,255,255) rough=0.045
```

`Specular Tint` 远大于 1 时整片高光饱和，车身颜色被吃掉 —— 就是"像镀铬、看不见颜色"。

全库统计：**296 个材质里 139 个有分量 > 1.0**（`animspec`/`basicspec` 是 400、
`car_alpha`/`car_badge_chrome` 是 255、`asphalt` 是 128），说明 0–255 是全局约定。

### 3.2 修法

```python
if rm.spec_colour is not None:
    _set_input(bsdf, "Specular Tint",
               (*[min(1.0, max(0.0, c / 255.0)) for c in rm.spec_colour], 1.0))
```

修后实测（P1，6 套涂装）：

```

bsdf_2 rough=0.447 coatW=1.0 specTint=(0.35, 0.63, 0.82)  蓝 car_paint_metallic_cool

```

## 4. 按涂装表决定谁需要多预设

### 4.1 涂装表怎么说的（P1 实测）

```
paint 01  materials 0    texture overrides 2
paint 02  materials 0    texture overrides 2
paint 03  materials 73   texture overrides 2
paint 04  materials 73   texture overrides 2
paint 05  materials 73   texture overrides 2
paint 06  materials 0    texture overrides 2

LOD_A_BODY_mm_ext     part_slot=30   overridden_by=[03, 04, 05]
LOD_A_TYRE_mm_tyre    part_slot=639  overridden_by=[]      ← 轮胎
LOD_A_WHEEL_mm_wheel  part_slot=729  overridden_by=[]      ← 轮毂
```

轮胎、轮毂、刹车盘、底盘在任何涂装下都不变，给它们 6 套一模一样的预设既浪费也没意义。

### 4.2 修法：签名去重时把 `paint_rgb` 只算给车漆

```python
@staticmethod
def _signature(rm) -> tuple:
    # paint_rgb is the body colour and only paint materials use it; leaving it
    # out for everything else is what lets a tyre's six schemes collapse to one.
    is_paint = (rm.material or "").startswith(gamematlib.PAINT_PREFIXES)
    return (rm.material, rm.texture_file, rm.fresnel, rm.specular,
            round(rm.roughness, 4), round(rm.metallic, 4),
            None if rm.coat is None else round(rm.coat, 4),
            rm.paint_rgb if is_paint else None)
```

以及 `_build()` 里签名全同的部件只建 1 个预设：

```python
if len(distinct) == 1:
    name = f"{self.car}_{first.material}"
    presets = [(resolved[0][0], resolved[0][1], first,
                _image_for_path(first.texture_file, self._images),
                _ramp_image(self.depot, first.fresnel, self._ramps),
                _ramp_image(self.depot, first.specular, self._ramps))]
else:
    name = f"{self.car}_{first.material}_paint"
    presets = [... 每涂装一条 ...]
```

`_apply_game_materials()` 也改成按材质实际预设数写属性，`Switch paint scheme` 对单预设材质是空操作。

## 7. 环境备忘

- depot：`E:\DXT_480x320+960x640+2048x1536数据包-Build260716\files\.depot`。
  路径含中文，pwsh here-string 里写死会变乱码，用 `glob.glob(r"E:\DXT*Build260716")[0]` 动态取。
- Blender headless 的 stderr 有几百行 `Failed to remove: ... PermissionError(13, '拒绝访问。')`
  （扩展清理噪音，与测试无关）。**stdout 要单独重定向到文件**，只看 stdout 会被噪音盖住；
  `Select-String` 过滤必须加 `-CaseSensitive`，否则 `FAIL` 会匹配到 `Failed to remove`。
- `bpy.ops.import_scene.rr3_vehicle` 只认 `filepath=`，用 `directory=` 会报
  `keyword "directory" unrecognized`。
- Blender 4.5 的 `Mesh` **没有** `.normals` 属性，查自定义法线用 `me.has_custom_normals`。
- `bpy.data.objects["BODY"]` 不存在，车身对象名是 `LOD_A_BODY_mm_ext`，
  用 `ob.get("rr3_mesh_name")` 找最稳。

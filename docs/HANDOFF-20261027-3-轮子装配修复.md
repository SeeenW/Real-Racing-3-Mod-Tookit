## 0. 一句话结论

**整车导入现在是"先导 points，再按 points 位置装轮子，动画同一套微调"。**
轮子枢轴直接取 `ANCHOR_POINT_WHEEL_*` 的位置（实测偏差 0.000 mm），
轮子局部坐标系的 `x = 0` 就是外侧面、正好贴在该 point 上（不做任何居中），
右轮是绕竖轴转半圈而不是镜像，模型原点在地面所以**没有任何 Y 方向偏移**。
朝向/镜像由一个根空物体承担，车身/轮子/尾翼/锚点整体转，不会互相错位。

刹车盘和卡钳用**同一个径向系数**一起装（卡钳不跟轮子转）；`all_lods` 可一次导入
全部 8 级、每级一个集合；LOD F 的轮子本来就是装好的整车网格，直接放世界原点不缩放。

## 2. 实际改了什么

### 2.1 `rr3lib/parts.py` —— `height_offset` 归零

`build_plan()` 原来按四个轮心 y 的平均值算 `a.height_offset`，再从
`m.position` / `a.anchors` / `a.steering` 里减掉。结果轮子枢轴落到 y≈0、
锚点被抬高 0.34 m —— 这就是 bug 2 的根因。

现在（`rr3lib/parts.py:326-345`）：

```python
a.height_offset = 0.0
if a.points_file:
    pf = pointslib.load(a.points_file)
    for rec in pf.records:
        if rec.position is not None:
            p = anim_to_model(tuple(v * POINT_SCALE for v in rec.position))
            a.anchors.append((rec.name, p))
            if rec.name == STEERING_ANCHOR:
                a.steering = p
```

`height_offset` 字段保留（`AeroPart.height_offset`、`frames()` 里的
`p[1] - self.height_offset` 都还在），值恒为 0，不破坏 API。
`build_plan()` 里 `aero_parts(...)` 的调用显式传 `0.0`，注释说明
"wing banim 枢轴已经是模型空间，任何地方都不再加偏移"。

### 2.2 `WheelSet` 两个新字段 + `wheel_set()` 找 `TYRE_REAR`

```python
#: True when ``rear_tyre`` is a mesh of its own (``TYRE_REAR``)
rear_tyre_own: bool = False
#: True when ``rear_wheel`` is a mesh of its own (``WHEEL_REAR``)
rear_wheel_own: bool = False
```

```python
ws.front_wheel = pick(prefix + "WHEEL_mm_wheel")
ws.front_tyre = pick(prefix + "TYRE_mm_tyre", prefix + "TIRE_mm_tyre")
rear_wheel = pick(prefix + "WHEEL_REAR_mm_wheel")
rear_tyre = pick(prefix + "TYRE_REAR_mm_tyre", prefix + "TIRE_REAR_mm_tyre")

ws.rear_wheel = rear_wheel or ws.front_wheel

```

### 2.3 `rr3_blender_addon/__init__.py` —— 轮子装配循环重写

新增两个辅助：

```python
def _point_model_location(raw, convert, scale=1.0):
    """A .points record as a Blender location, in the model's own frame."""
    x, y, z = (float(c) / pointslib.POINT_SCALE for c in raw)
    return Vector(_to_blender((x, z, -y), convert)) * scale


def _mesh_width(md):
    """Extent of a mesh along its own x axis (the wheel's width axis), or None."""
    if md is None or not md.positions:
        return None
    xs = [p[0] for p in md.positions]
    if not xs:
        return None
    return max(xs) - min(xs)
```

`_import_points(...)` 加 `model_space: bool = False`：为 True 时走
`_point_model_location` 并直接赋值（已经是米、已在模型帧）；默认 False 保持
原来的 `_points_frame(facing, mirror_x) @ _anchor_to_blender(...) + /POINT_SCALE`
（独立导入器的 FBX 语义不变）。

轮子循环（原 `:569-616` → 现 `:639-756`）的核心：

```python
loc = anchor_loc.get("ANCHOR_" + mount.name)
if loc is None:
    loc = _point_model_location(mount.raw, convert_axes,
                                pos_scale * pos_factor) + dy_bl
pivot.location = loc
attach(pivot)

rear = not mount.steer
wheel_name = plan.wheels.rear_wheel if rear else plan.wheels.front_wheel
tyre_name = plan.wheels.rear_tyre if rear else plan.wheels.front_tyre
k = wheel_fit.factor(rear) if wheel_fit is not None else 1.0
k *= wheel_scale

widen = 1.0
if (rear and rear_tyre_width and not plan.wheels.rear_tyre_own
        and front_w > 1e-6 and rear_w is not None and rear_w > 1e-6):
    widen = rear_w / front_w
    if not (0.6 <= widen <= 1.6):
        widen = 1.0

for mesh_name, is_tyre in ((wheel_name, False), (tyre_name, True)):
    md = by_name.get(mesh_name)
    if md is None:
        continue
    w = widen if is_tyre else 1.0
    mat = None
    if w != 1.0 or mount.corner.endswith("R"):
        mat = Matrix.Identity(4)
        if w != 1.0:
            mat = Matrix.Scale(w, 4, (1.0, 0.0, 0.0)) @ mat
        if mount.corner.endswith("R"):
            # Half a turn about the wheel's own vertical axis, not a mirror
            mat = Matrix.Rotation(math.pi, 4, "Y") @ mat
    ob = _build_mesh_object(md, 1.0, convert_axes, coll,
                            (0.0, 0.0, 0.0), images, matrix=mat)
    ob.parent = pivot
    ob.matrix_parent_inverse = Matrix.Identity(4)
    if abs(k - 1.0) > 1e-6:
        ob.scale = (1.0, k, k)
    ob["rr3_wheel"] = mesh_name
    ob["rr3_wheel_scale"] = k
    if w != 1.0:
        ob["rr3_tyre_widen"] = w
```

**与旧代码的 4 个本质差别**：

1. 枢轴位置取锚点（不再 `cm @ mount.position * pos_scale`，那用的是减过
   `height_offset` 的值）
2. `off = (0,0,0)`，**不做三轴居中**（旧代码把 x 也居中，把轮子推到 point 两侧
   各一半）
3. 右侧用 `Matrix.Rotation(math.pi, 4, "Y")` 在模型空间做 `(x,y,z) → (-x,y,-z)`，
   等价于 `x = -x, z = -z`；旧代码的 `ob.rotation_euler = (0, 0, pi)` 少了 z 反号，
   是"转 + 镜像"而不是"转半圈"
4. 后胎按轮辋宽度比 `Matrix.Scale(w, 4, (1,0,0))` 拉宽（**只有 x**，与径向
   `(1.0, k, k)` 正交）

`_build_mesh_object(md, scale, convert, coll, offset, images, matrix=None)` 的
`matrix` 是模型空间的 4×4，在 Y-up→Z-up 之前套用，法线用
`matrix.to_3x3().inverted_safe().transposed()` 同步。

**朝向/镜像由一个根空物体承担**：

```python
root = None
if facing != "+Y" or mirror_x:
    root = bpy.data.objects.new(f"{car}_ROOT", None)
    root.empty_display_type = "PLAIN_AXES"
    root.empty_display_size = 0.5

def attach(ob):
    if root is not None:
        ob.parent = root
        ob.matrix_parent_inverse = Matrix.Identity(4)
    return ob
```

`attach()` 用于车身全部对象、锚点、`WHEEL_*` 枢轴、`STEERING_WHEEL`、
`AERO_*` 枢轴。**不能逐对象施加**——那样每个零件会绕自己的原点转，
车身转了轮子会离开轮拱。

`delta_axes` 是**逐轴**的差值，优先于 `rot_mode`：

```python
samples = part.frames() or [(0.0, part.pivot, part.rest_rotation)]
r_first = partslib.euler_xyz(*samples[0][2])
if any(delta_axes):
    base = samples[0][2]
    samples = [(t, p, tuple((r[i] - base[i]) if delta_axes[i] else r[i]
                            for i in range(3)))
               for t, p, r in samples]
    samples = [(t, p, partslib.euler_xyz(*r)) for t, p, r in samples]
    rest_bl = Matrix.Identity(3)
elif rot_mode == "DELTA":
    ...
```

`pos_factor` 接入**所有**位置（这就是用户要的"动画也如此"）：

- 锚点：`ob.location = (ob.location * (pos_scale * pos_factor)) + dy_bl`
- 轮子回退路径：`_point_model_location(mount.raw, convert_axes, pos_scale * pos_factor)`
- `STEERING_WHEEL`、`AERO_*` 枢轴：同上
- `apply_pose()` 内：`loc_bl = cm @ (Vector(pos_model) * (pos_scale * pos_factor)) + dy_bl`
  （注释：*the animation is authored in the same space as the .points file,
  so it takes the same position scale*）

Operator 侧新增 5 个属性（`pos_factor` / `facing` / `mirror_x` /
`rear_tyre_width` / `delta_axes`），`from bpy.props import` 加了
`BoolVectorProperty`。

## 3. 关键几何事实（实测，别再去查）

**① 模型原点在地面，不是轮心高度。**
`_a.m3g` 车身顶点最低点：LFA y=0.113、Huayra y=0.102、Chiron Sport y=−0.178、
Caterham y=−0.126、250 GTO y=−0.172。轮心高度（`.points`）LFA 0.336 /
Huayra 0.319 / Chiron 0.341。**轮心高 ≈ 一个轮胎半径，轮子站在 y=0 上，
所以不需要任何 height_offset。**

**② 引擎空间 == Blender 空间（数值上完全相同）。**
`POINT_WHEEL_FL` 在引擎里是 `(-0.9263, 1.290, 0.3361)` 米，导入 Blender 后也是同值。
推导：`.points` 原始值 ×1/32 → 引擎米制 → `anim_to_model` 得模型 `(x, z, -y)` →
`_to_blender` 得 `(x, -z, y)` → **两次抵消**。

**③ 轮子局部坐标系**（MonkeyTool `nfsnl_rr3.cpp:2526-2540` 注释，已核对）：
- `x = 0` 平面是轮子的**外侧面**（辐条面），`+x` 朝内朝刹车
- `POINT_WHEEL_xx` 在车身外缘，所以 `x = 0` 正好落在该 point 上，**什么都不居中**
- 未变换时这是车的**左侧**（x<0），所以 "LEFT" 卡钳在 +x
- 右侧 = 同一个轮子**绕竖轴转半圈**（`x=-x, z=-z`），**不是镜像**
  （镜像会让轮辋字反着读）
- 缩放只拉 `y`/`z`（径向），`x`（宽度）不动；法线 `y/z /= scale`

**④ 实测 bbox**：LFA `TYRE` x[0.0032, 0.2279]、y[−0.2993, 0.2992]、
z[−0.2976, 0.2976] —— y/z 已以 0 为中心，**只有 x 需要处理**。
但个别网格有 −0.02 的外凸唇（Chiron 轮辋 −0.0098、Caterham 轮胎 −0.0008、
250 GTO 轮胎 −0.0194），所以"锚点在网格端面上"的容差是 5% 而不是 2%。

### 4.1 后轮胎法线丢失（2026-10-28 补修）

用户报「Huayra 的后轮胎法向丢失了，前轮胎正常」。根因在
`rr3_blender_addon/__init__.py` 的 `_build_mesh_object()`：

```python
normals = [
    _to_blender(tuple(nrm_mat @ Vector(n)).normalized(), convert)   # 错
    for n in md.normals
]
```

`tuple()` 的结果没有 `.normalized()` 方法，抛 `AttributeError`；而这段被
`except Exception: pass` 静默吞掉，于是**凡走 matrix 分支的网格都丢法线**。
matrix 分支只在两种情况进入：右侧轮（`Matrix.Rotation(pi, 4, "Y")`）和后轮
拉宽（`Matrix.Scale(w, 4, (1,0,0))`）。Huayra 是唯一同时命中后者的车（后胎
拉宽 1.230），所以只有它的后胎出问题；其它车的右轮其实也丢了法线，只是对称
看不出差别。

修法两处：

```python
# 1) 先归一化再 tuple()
normals = [_to_blender((nrm_mat @ Vector(n)).normalized(), convert) for n in md.normals]
# 2) 不再静默：保留 try/except 但打印告警
except Exception as exc:  # noqa: BLE001
    print(f"warning: {md.name}: custom normals dropped ({exc})")
```

实测修复后 Huayra 8 个轮子网格 `has_custom_normals=True`，`flipped=0`。
新增两条断言（`every wheel keeps its custom normals` /
`wheel normals point outward`）把这一类"静默吞异常"钉住。

> **Blender headless 的噪音**：stderr 会有几百行
> `Failed to remove: ... PermissionError(13, '拒绝访问。')`（`extensions\.local` 下
> 的 mmgpy/PIL 被占用）。这是 Blender 自己的扩展清理，与测试无关。过滤时
> `Select-String` 必须加 `-CaseSensitive`，否则 `FAIL` 会匹配到 `Failed to remove`。
